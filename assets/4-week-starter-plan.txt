JORDAN VALE TRAINING — 4-WEEK STARTER PLAN
==========================================

Train 3 days a week (e.g. Mon / Wed / Fri). Rest 60–90 s between sets.
Pick a weight you could lift 2–3 more reps with. Add a little weight or one rep each week.

WORKOUT A
  Goblet squat ............. 3 x 8
  Push-up (incline if needed) 3 x 8
  Dumbbell row ............. 3 x 10 each side
  Glute bridge ............. 3 x 12
  Plank .................... 3 x 30 s

WORKOUT B
  Romanian deadlift (DB) ... 3 x 8
  Overhead press (DB) ...... 3 x 8
  Lat pulldown or band pull  3 x 10
  Reverse lunge ............ 3 x 8 each leg
  Dead bug ................. 3 x 8 each side

SCHEDULE
  Week 1: A / B / A
  Week 2: B / A / B
  Week 3: A / B / A  (+1 set on the first two exercises)
  Week 4: B / A / B  (+1 set on the first two exercises)
